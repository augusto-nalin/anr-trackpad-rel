# ANR's Trackpad & Touchpad Tweaks (anr-trackpad)

Trackpad gestures, aim assist and macOS fixes for Minecraft 1.12.2 (Forge), on
Apple Silicon Macs.

## Requirements
- Minecraft 1.12.2, Forge 14.23.5.2860+
- Apple Silicon Mac (arm64 Java 8, e.g. through Prism Launcher)
- **Required:** [MixinBooter](https://www.curseforge.com/minecraft/mc-mods/mixin-booter)

## Reporting a bug
Open an [issue](../../issues/new/choose) with your Minecraft / Forge / anr-trackpad
versions, your Mac model and macOS version, steps to reproduce, and your
`logs/latest.log`.

## About this repository
This repository hosts the issue tracker and `update.json`, which Forge's update
checker reads to show "update available" in the Mods list. The mod's source is
not published here.
